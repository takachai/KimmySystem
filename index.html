Telegram bot

Connect as many Telegram chats or groups as you need – add a new bot slot for each one. Each slot has its own task list, reminders and controls. Use one bot for all groups, or a different bot for each.
Customer quick order: people can message this bot privately to order from your catalog in a few steps. Each order is saved in Orders and alerts you in the app and in this group.
  1. In Telegram, open @BotFather, send /newbot and copy the token it gives you.
  2. Paste the token in a slot. For a private chat, send your bot a message. For a group, add the bot to the group and send any message there, such as /start.
  3. Click "Find chat ID", then "Save & connect". The bot posts one confirmation in that chat; send /start there whenever you want the quick buttons.
Each group has the quick buttons: ➕ Add task, ⏱ Timer, 📋 Tasks, 📅 Today, ⚠️ Overdue, 🛠 Installation, 📊 Status. A group only sees the tasks sent to it, and tasks added in a group are sent to that group. "Save & connect" and "Send test" both post the full menu, so the buttons appear as soon as the bot is added. If you still do not see them, send /start in the group.
Groups: make the bot a group admin so it can delete dangerous files and 18+ content. To let it see button taps, make it admin or turn off Group Privacy in @BotFather (/mybots, Bot Settings, Group Privacy, Turn off). Everyone in a connected group can control that group's tasks, so only connect groups you trust.
Important: reminders and bot replies only run while this page is open in a browser (a minimized tab is fine). The tokens are kept in this browser only and are never included in backups, the data folder or Google Drive.
